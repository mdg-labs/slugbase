# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for a security problem.

- **Preferred:** [report it privately on GitHub](https://github.com/mdg-labs/slugbase/security/advisories/new).
- **Or email:** support@slugbase.app

You'll get an acknowledgement within 3 working days. Critical and high-severity issues are targeted for a fix within 30 days; the advisory is published 7 days after a fixed release is available, and reporters are credited if they wish.

## Scope

The SlugBase Community Edition in this repository and the official images built from it. The hosted SlugBase Cloud service is in scope too: report it the same way.
