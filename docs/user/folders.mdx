**Folders** lists your folders, and the folders other members shared with you. A folder groups related bookmarks, such as everything for one project.

<Screenshot alt="The Folders page with the list of folders and their bookmark counts" />

## Prerequisites

- You are signed in and a workspace is open.

## How folders work

- A bookmark can be in several folders.
- Deleting a folder never deletes the bookmarks in it.
- Folders are flat. A folder cannot hold another folder.
- A folder is private to you until you share it. Only the owner of a bookmark can put it in a folder, and only in the owner's own folders.
- The sidebar lists your folders under **Folders**. Choose one to open **Bookmarks** with only that folder.

## Create a folder

1. Choose **New folder**, or press `N` on this page.
2. Enter a **Name**. Use 1 to 64 characters. You cannot use the same name twice.
3. Optional: search for an **Icon**, and pick a **Colour**.
4. Choose **Create folder**.

**Result:** SlugBase says **Folder created.** and the folder appears in the list.

You can also create a folder while you save a bookmark. See [Add and Edit Bookmarks](add-and-edit-bookmarks.mdx).

## Find folders

1. Under **Folders to show**, choose **Mine** or **Shared with me**.
2. Under **Sort by**, choose **Name**, **Bookmarks** or **Recently updated**.

The list shows the **Name**, the number of **Bookmarks**, **Sharing** and **Updated**. Choose **Load more** under the list to see further folders.

The **Sharing** column says **Private**, or who the folder is shared with, for example "Shared with you by" and the owner's name for a folder another member shared with you. You can read a folder shared with you and the bookmarks in it, but only its owner can change it.

## Change or delete a folder

Open the actions menu, **Actions for** and the folder's name, and choose:

| Action | What it does |
| ------ | ------------ |
| **Open in Bookmarks** | Shows the bookmarks of this folder in **Bookmarks**. |
| **Rename** | Opens **Rename folder**. Enter a new name and choose **Save changes**. |
| **Change icon and colour** | Opens a form for the icon and colour. Choose **Save changes**. |
| **Share settings** | Opens the share dialog. It appears only where your workspace can share. |
| **Delete** | Asks "Delete" and the folder's name. Choose **Delete folder** to confirm. |

**Result of a delete:** SlugBase says **Folder deleted.** The confirmation tells you what stays: for a folder with 9 bookmarks, "The 9 bookmarks stay; only the folder goes."

## Field and option reference

| Field / option | Description | Required |
| -------------- | ----------- | -------- |
| Name | 1 to 64 characters, unique among your folders. | Yes |
| Icon | One icon from a set of about 60. Search them by name. | No |
| Colour | One of eight: Periwinkle, Green, Amber, Red, Blue, Purple, Pink or Mint. | No |

## Troubleshooting

### The form says "You already have a folder with this name."

Folder names are unique among your own folders, and capitals do not count. Choose another name.

### The form says "This folder was changed somewhere else."

Close the form and open it again to see the latest version.

### The page shows "No folders yet"

You have no folders. Choose **New folder**. Under **Shared with me**, the page says "Nothing has been shared with you yet" until another member shares a folder.

### The folders could not be loaded

SlugBase says "The folders could not be loaded. Try again in a moment." Choose **Try again**.
