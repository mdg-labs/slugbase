## What you'll accomplish

After this guide, you can search from the Bookmarks page and command palette, use dashboard search, and import bookmarks from browser export files.

## Prerequisites

- Signed in to an active workspace
- For import: a browser bookmark export file (Netscape HTML or JSON)

## Search bookmarks

SlugBase offers several search entry points:

| Location | Placeholder / behavior |
|----------|----------------------|
| **Bookmarks** page | **Search title, URL, or slug…** — filters the list |
| **Command palette** (`⌘K` / `Ctrl+K`) | **Search bookmarks or type a command…** — quick open and navigation |
| **Home** dashboard | **Search bookmarks, folders, and tags…** — opens palette-style search |

### Combine search with filters

On **Bookmarks**, search works together with:

- **Folder** — all folders or one folder
- **Tags** — one or more tags
- **Pinned** — pinned only

Use **Clear filters** when the list shows **No bookmarks match** but you expect results.

### Sort search results

Change sort order with **Sort** — recently added, recently accessed, alphabetical, or most used — without clearing your query.

### Palette deep search

When the palette finds many bookmark matches, choose **See all N bookmarks matching "…"** to continue on the Bookmarks page with the same query.

See [Command palette](/selfhosted/command-palette) for keyboard-driven search.

## Import from a browser

Import brings existing bookmarks into your workspace in one step. Supported formats:

- **Netscape HTML** (`.html`) — common export from Chrome, Firefox, and Safari
- **JSON** export files from supported browsers

During [first workspace setup](/selfhosted/first-workspace-setup), onboarding step **Import your bookmarks** accepts a drag-and-drop file. You can import later from:

- **Home** → **Getting started** checklist → **Import from browser**
- **Bookmarks** → **Import from browser**

### Import during onboarding

<Steps>
  <Step title="Open the import step">
    After setup, reach **Import your bookmarks** (step 2 of 4) or skip and import later.
  </Step>
  <Step title="Drop or browse for a file">
    Drop a file on **Drop a file here** or click to browse. Hint text lists **Netscape HTML (.html) or JSON export · Chrome, Firefox, Safari**.
  </Step>
  <Step title="Wait for completion">
    While importing, the UI shows **Importing…**. Success displays **{count} bookmarks imported**.
  </Step>
  <Step title="Continue or skip">
    Click **Import & continue** or **Continue without importing**. You can **Skip for now** at any time.
  </Step>
</Steps>

### Import from Bookmarks later

Click **Import from browser** on the Bookmarks page. Use the same file types as onboarding. Large libraries may take a moment — wait for the success confirmation before navigating away.

<Callout kind="tip">
Imports are capped per request (thousands of bookmarks). Split very large exports if an import fails, or contact your operator for limits on your instance.
</Callout>

## What import creates

Imported bookmarks become normal workspace bookmarks. They may not have slugs or forwarding enabled until you edit them. Review imports on the Bookmarks page, assign [folders](/selfhosted/folders) and [tags](/selfhosted/tags), and add slugs where you want [go forwarding](/selfhosted/slugs-and-go).

## Export (related)

For backup and migration **out** of SlugBase, use workspace export features documented in [Backup and export](/selfhosted/backup-and-export). Import and export are separate flows — export produces an enriched archive for restore or migration.

## Verify it worked

- Search on Bookmarks returns expected titles or URLs
- After import, the bookmark count on **Home** increases
- A spot-check of imported URLs opens correctly from the list

## Troubleshooting

### Import failed

- Confirm the file is Netscape HTML or supported JSON
- Retry with a smaller export if the file is very large
- Check file size limits — oversized HTML exports are rejected

### Search returns nothing

Clear **Folder**, **Tags**, and **Pinned** filters. Verify the active workspace in the top bar.

### Imported bookmarks missing slugs

Import does not auto-assign forwarding slugs. Edit bookmarks individually or use bulk tag/folder actions, then add slugs in the editor.
