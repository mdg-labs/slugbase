## What you'll learn

After reading this page, you will understand what SlugBase does on your own infrastructure, how it differs from SlugBase Cloud, and which guides to read next.

## What is SlugBase?

SlugBase is a bookmark manager with built-in URL shortening and keyboard-driven navigation. You save links in a **workspace**, assign short **slugs** to bookmarks, and jump to any destination from the address bar or command palette using **forwarding** (`/go/<slug>`).

On a self-hosted instance you run the same product as SlugBase Cloud — one codebase, configured for your deployment. Your data stays on infrastructure you control.

## How self-hosted works

A self-hosted SlugBase instance ships as a **combined container image** (API and web client on one port). You provide **PostgreSQL** for persistence and set environment variables for secrets, public URLs, and optional integrations.

Typical shape:

```text
Your reverse proxy (HTTPS)
        ↓
SlugBase container (port 3000)
        ↓
PostgreSQL
```

## Key concepts

### Workspace

A **workspace** is the top-level container for bookmarks, folders, tags, members, and settings. Every piece of data belongs to exactly one workspace. On self-hosted, an **instance-wide administrator** creates workspaces and places members by invitation — public registration is off by default.

### Slug and forwarding

A **slug** is a short keyword on a bookmark (for example `docs`). When **forwarding** is enabled, signed-in workspace members can open `/go/<slug>` to jump to the bookmark's URL. Slugs are private to your workspace; they are not anonymous public short links.

### Folders and tags

**Folders** organize bookmarks into named containers. A bookmark can belong to multiple folders. **Tags** are flexible labels you can filter and search by — use both together when folders give structure and tags give cross-cutting themes.

## Self-hosted vs SlugBase Cloud

| Topic | Self-hosted | SlugBase Cloud |
|-------|-------------|----------------|
| Hosting | Your infrastructure | Managed by SlugBase |
| Billing | Not applicable — full entitlements on your instance | Free, Personal, and Team plans |
| User onboarding | Setup + invite by default | Public registration with email verification |
| SMTP and OIDC | Configure in **Settings → Workspace** | Operator-managed on cloud; some settings hidden |
| Marketing site | Separate deployment (not in the container image) | Hosted separately |
