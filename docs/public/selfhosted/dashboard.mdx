## What the dashboard is for

The dashboard is the default page after you sign in. In the sidebar it appears as **Overview**; the app route is `/`. You get counts for your library, shortcuts to **Bookmarks**, **Folders**, and **Tags**, sections for pinned and frequently used shortcuts, and a large command bar that opens the global command palette (same as the **Ctrl+K** / **⌘K** shortcut registered app-wide).

<Callout kind="info">
  This guide applies to **self-hosted** SlugBase. The same core UI exists in cloud; plan-specific banners and limits there are described in the [Cloud guides](/cloud/introduction).
</Callout>

## Before you start

You need a working install and an account. If you still see the setup wizard, finish [First run setup](/selfhosted/first-run-setup) first.

## How to move around from the dashboard

<Steps>
  <Step title="Open Overview" icon="layout-dashboard" titleType="p">
    In the sidebar, choose **Overview** (or go to `/` on your app base URL).
  </Step>
  <Step title="Use the command bar" icon="search" titleType="p">
    Select the search field under the hero text (placeholder: **Type a command or search bookmarks**), or press **Ctrl+K** (**⌘K** on Mac). That opens the command palette; see [Bookmarks](/selfhosted/bookmarks) for full behavior.
  </Step>
  <Step title="Jump to folders" icon="bookmark" titleType="p">
    Use the stat row links for **bookmarks**, **folders**, and **tags**, or the quick cards if shown—they navigate to **Bookmarks**, **Folders**, and **Tags** respectively.
  </Step>
</Steps>

## What you see on the page

| Area | Purpose |
| --- | --- |
| **bookmarks** / **folders** / **tags** | Library size; the stat cards show these lowercase labels; each links to the matching page. |
| **Quick access bookmarks** | Bookmarks you open often that have a shortcut (slug); subtitle explains they are ranked by use. |
| **Pinned** | Items you pinned on the Bookmarks page (**Pin**); empty state suggests going to **Bookmarks**. |
| **Most Used Tags** | Tags ranked by usage; choosing one filters **Bookmarks** by that tag. |
| **Shared with you** | When you have shared items, cards link to **Bookmarks** or **Folders** scoped to **Shared with me**. |

Optional banners may appear: a dismissible **Pro Tip: Browser integration** whose inline guide link reads **Set up search engine**, and a **Get started** checklist whose steps include **Set up browser search engine shortcut** (same guide as the pro tip link, but a different label). The pro tip's close control is **Dismiss**; the checklist footer is **Dismiss checklist**.
