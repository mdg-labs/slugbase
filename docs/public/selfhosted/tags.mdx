## What you'll accomplish

After this guide, you can create tags, apply them to bookmarks, filter lists by tag, and manage tag names from the Tags page.

## Prerequisites

- Signed in to an active workspace

## What tags are

**Tags** are short labels you attach to bookmarks. Unlike folders, tags are lightweight markers — use them for themes (`reading`, `ops`, `q4`) that span many folders. Filter Bookmarks and the command palette by tag to narrow results quickly.

Tags in SlugBase are **private to your workspace membership** — manage them from your account's tag list.

## Open Tags

Select **Tags** from the sidebar. The page lists all tags with usage counts and sort options (alphabetical, most used, recently created).

## Create a tag

<Steps>
  <Step title="Click New tag">
    On the Tags page, click **New tag**.
  </Step>
  <Step title="Enter a name">
    Type a tag name (placeholder suggests `tag-name` style) and click **Create**.
  </Step>
  <Step title="Optional: color">
    When creating or editing, pick a **Color** or leave **None**.
  </Step>
</Steps>

You can also create tags while editing a bookmark — search in **Tags** and create inline.

## Apply tags to bookmarks

From the **New bookmark** or **Edit bookmark** modal:

1. Focus the **Tags** field
2. Search existing tags or type a new name
3. Select tags to attach; remove with the tag dismiss control
4. Save the bookmark

For many bookmarks, use bulk **Tags** actions on the Bookmarks page to add or remove tags at once.

## Filter by tag

On **Bookmarks**, open the **Tags** filter and select one or more tags. The list shows only matching bookmarks. Combine with folder and pinned filters as needed.

**Home** shows **Most used tags** with links to the Tags page.

## View bookmarks for one tag

Click a tag row to open the detail panel. It shows how many bookmarks use the tag and links to **View all in Bookmarks**.

## Rename or delete a tag

From the Tags list or detail panel:

| Action | Result |
|--------|--------|
| **Rename tag** | Updates the name on all attached bookmarks |
| **Delete tag** | Removes the tag and untags affected bookmarks |

Deletion asks for confirmation and reports how many bookmarks will be untagged.

## Verify it worked

- The tag appears in the Tags list with an accurate count
- Filtering Bookmarks by the tag shows the expected bookmarks
- Renaming updates the tag everywhere it appears

## Troubleshooting

### No tags yet

Create a tag from the Tags page or from a bookmark's **Tags** field. The command palette can also create tags via **New tag**.

### Search shows no tags

Clear the search field with **Clear search** or check spelling.

### Deleted tag still on a bookmark card

Refresh the page — deletion untags bookmarks immediately; cached lists update on navigation.
