## What you'll accomplish

After this guide, you can create folders, assign bookmarks to them, filter by folder, and open a folder's bookmarks from the Folders page.

## Prerequisites

- Signed in with permission to create folders in the active workspace

## What folders are

**Folders** are named containers for organizing bookmarks. A bookmark can belong to **multiple folders**. Folders can be shared with workspace members or teams — sharing a folder grants read access to the bookmarks it contains.

SlugBase uses **folder** — not collection — as the product term.

## Open Folders

Select **Folders** from the sidebar. The page shows every folder you can access with search and sort controls.

Sort by alphabetical order, most bookmarks, or recently created.

## Create a folder

<Steps>
  <Step title="Click New folder">
    On the Folders page, click **New folder**.
  </Step>
  <Step title="Name the folder">
    Enter a **Folder name** (for example `Reading List`) and click **Create**.
  </Step>
  <Step title="Optional: icon and color">
    When editing folder details, set an **Icon** and **Color** to distinguish folders in the list.
  </Step>
</Steps>

A toast confirms **Folder created**.

## Add bookmarks to folders

Folders are assigned from the bookmark editor:

1. Open **New bookmark** or **Edit** on an existing bookmark
2. In **Folders**, search or select one or more folders
3. Type a new name and choose **Create "…"** to make a folder inline
4. Save the bookmark

You can also move multiple bookmarks with **Move to folder** in bulk selection mode on the Bookmarks page.

## Open bookmarks in a folder

From the Folders list:

- Click a folder card to browse its bookmarks
- Use **Open in Bookmarks** from the row menu to jump to the Bookmarks page filtered to that folder

The Bookmarks **Folder** filter shows **All folders** or a specific folder.

## Rename or delete a folder

Open **More options** on a folder row:

| Action | Result |
|--------|--------|
| **Rename** | Change the folder name |
| **Open in Bookmarks** | View bookmarks in this folder |
| **Share settings** | Adjust sharing (when entitled) |
| **Delete folder** | Removes the folder; bookmarks move to your default folder |

Deleting asks for confirmation: bookmarks in the folder are **not** deleted — they are moved to your default folder.

## Filter folders

Use the search field to filter by folder name. If nothing matches, SlugBase shows **No folders match** — clear filters or widen the sharing scope.

## Folders on Home

**Home** includes a **Folders** section with quick links. An empty state prompts you to **Create a folder to organize bookmarks**.

## Verify it worked

- The new folder appears on the Folders page with the correct bookmark count
- Bookmarks assigned to the folder appear when you filter Bookmarks by that folder
- Renaming updates the name everywhere it is shown

## Troubleshooting

### Could not create the folder

Retry after checking your connection. Ensure you have permission to manage folders in the workspace.

### Bookmarks disappeared after deleting a folder

Bookmarks were moved to your default folder — search on the Bookmarks page or clear folder filters.

### No folder cap

Unlike some hosted plan messaging in other products, SlugBase does not cap folder count. Organize freely within your workspace.
