## What this page is for

**Folders** (`/folders`) groups bookmarks. Each folder has a **Folder Name** and optional icon; bookmarks can belong to one or more folders from the bookmark editor. The page subtitle in the app is **Group bookmarks and share them with your team.**

<Callout kind="info">
  Folder and sharing behavior described here is what the **self-hosted** core ships. The hosted product may hide or gate some sharing UI by plan; see [Cloud guides](/cloud/introduction) for that product line.
</Callout>

## Before you start

You manage which bookmarks sit in a folder from **Bookmarks**—edit a bookmark and use **Folders** there. Empty folders are allowed.

## How to create or edit a folder

<Steps>
  <Step title="Open Folders" icon="folder" titleType="p">
    In the sidebar, choose **Folders**.
  </Step>
  <Step title="Create or edit" icon="plus" titleType="p">
    Select **Create Folder** for a new row, or use **Edit Folder** on an existing folder.
  </Step>
  <Step title="Save" icon="save" titleType="p">
    Enter **Folder Name** and optional icon, then save. Sharing is not configured here—use the row action **Share folder** (see below).
  </Step>
</Steps>

Deleting uses **Delete Folder**; a confirmation dialog shows the folder name before it is removed.

## Sort, scope, and pagination

- **Sort** — defaults to **Alphabetical**; you can switch to **Recently Added** via the toolbar (non-default sorts may show as a filter chip such as `Sort: …`).
- **Scope** — when scope tabs are shown: **All**, **Mine**, **Shared with me**, **Shared by me** (labels come from the bookmarks scope strings: **Mine**, **Shared with me**, **Shared by me**).
- **Per page** and **page** — adjust list size and move between pages; the header can show counts like **Showing x of y** when filters or pagination apply.

Use **Clear all** on filter chips to reset scope and sort to defaults.

## Working with bookmarks inside a folder

Select the folder **Name** in the table—it links to **Bookmarks** with that folder applied as the filter. You can also open **Bookmarks** and set **Filter by Folder** manually. The command palette jumps to **Bookmarks** with the same filter when you pick a folder from search results.

## Sharing

When sharing UI is enabled, the row action **Share folder** opens the share dialog to add people or teams (**Invite people or share with a team.**), including **Share with Teams** and related copy there—not in the create/edit folder modal (that modal is name and icon only).
