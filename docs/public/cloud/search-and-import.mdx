## What you'll accomplish

After this guide, you can search bookmarks, folders, and tags from the dashboard and list pages, and import bookmarks from a browser export file.

## Prerequisites

- Signed in to SlugBase Cloud
- Active workspace selected
- For import: a browser bookmark export file and room under your plan's bookmark limit

## Search bookmarks

SlugBase offers search in multiple places — all scoped to your **active workspace**.

### Dashboard search

The dashboard search field accepts queries across bookmarks, folders, and tags. Results open relevant list pages or palette-style matches.

### Bookmarks list search

On **Bookmarks**, use the search field to match **title, URL, or slug**. Combine search with folder, tag, and pinned filters. Use **Clear filters** when no results match.

### Folders and tags search

On **Folders** and **Tags**, search filters the list by name without leaving the page.

### Command palette

Press `⌘K` / `Ctrl+K` and type your query for the fastest global search. See [Command palette](/cloud/command-palette).

| Surface | What it searches |
|---------|------------------|
| Dashboard | Bookmarks, folders, tags |
| Bookmarks list | Title, URL, slug |
| Command palette | Bookmarks, folders, tags + actions |
| Folders page | Folder names |
| Tags page | Tag names |

## Import from a browser

Import migrates bookmarks from another tool in one step. SlugBase accepts:

| Format | Sources |
|--------|---------|
| Netscape HTML | `.html` exports |
| JSON | Structured bookmark export |

Common sources include **Chrome**, **Firefox**, and **Safari** export files.

### Import during onboarding

After your first sign-in, onboarding step 2 offers a drop zone for your export file. You can **Import & continue** or **Skip for now**.

### Import from the app

<Steps>
  <Step title="Open import">
    From the **Bookmarks** page, click **Import from browser**. You can also start import from the dashboard **Getting started** checklist.
  </Step>
  <Step title="Select your export file">
    Drop a `.html` or `.json` file into the drop zone, or click to browse.
  </Step>
  <Step title="Wait for completion">
    SlugBase imports bookmarks, creates folders and tags by name when present in the export, and skips invalid or duplicate slugs. A summary shows how many bookmarks were imported.
  </Step>
</Steps>

### Import limits and plan caps

Imports respect your workspace bookmark limit:

- **Free plan:** up to **50** bookmarks per workspace — import stops when the cap is reached
- **Personal** and **Team:** unlimited bookmarks

If import fails partway through because of the cap, the bookmarks imported before the limit still appear in your workspace. Upgrade to **Personal** to continue importing.

<Callout kind="tip">
Large exports may take a moment. Do not close the tab while **Importing…** is shown.
</Callout>

## What import creates

During import, SlugBase:

- Creates bookmarks from export entries
- **Matches or creates folders** by name from the export
- **Matches or creates tags** by name when tag data is present
- Skips entries with invalid URLs or slug conflicts

Review imported bookmarks on the **Bookmarks** list and assign slugs for forwarding as needed.

## Verify it worked

After import, the bookmarks list shows new entries and the dashboard stats update. Search for an imported title to confirm it is indexed.

## Troubleshooting

### Import failed

Confirm the file is a valid Netscape HTML or JSON export. Try re-exporting from your browser. If the error persists, retry with a smaller export batch.

### Fewer bookmarks than expected

You may have hit the Free **50**-bookmark cap. Check the import summary count and upgrade or remove bookmarks to free space.

### Duplicate bookmarks

SlugBase skips duplicates where possible. Clean up remaining duplicates manually from the bookmarks list.

### Search returns nothing

Confirm the active workspace in the workspace switcher. Clear filters on the bookmarks list. Try the command palette for a broader search.
