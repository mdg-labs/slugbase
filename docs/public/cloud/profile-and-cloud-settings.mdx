## What this page covers

Your **Profile** screen in the app (`/app/profile`) is where you manage personal settings: email, name, language, theme, API tokens, optional [two-factor authentication](/cloud/two-factor-authentication), optional AI suggestion toggles when your plan allows them, and account deletion. The layout and labels follow the core UI strings (for example **Account**, **Email**, **Name**).

## Cloud-specific behavior

- **Email verification:** Cloud requires email verification before you can log in. If you change your email on Profile, you'll get a new verification link to confirm the change.
- **Delete account:** Cloud may block deletion if you're the billing owner of a workspace. The app will explain what you need to do first (for example transferring ownership) before deletion is allowed.

For step-by-step detail on fields that are identical to self-hosted (tokens, theme options, language list), see [Profile and preferences](/selfhosted/profile-and-preferences) and [API tokens](/selfhosted/api-tokens).

## Open workspace admin from Profile

If your user can access workspace administration, Profile shows an **Admin** badge and you use the main navigation **Admin** entry. On Cloud, **OIDC** and **SMTP** admin tabs are not offered; you will see **Billing** as an extra tab for plan management. Which tabs appear for **Members**, **Teams**, and sharing depends on your [plan](/cloud/plans-and-limits).
