## What you use SlugBase Cloud for

SlugBase Cloud is the managed service at [slugbase.app](https://slugbase.app). You get the same core bookmark manager in the browser—dashboard, bookmarks, folders, tags, import and export, slugs and `/go/` forwarding—while the operator hosts the stack, runs workspaces and billing, and applies [plans and limits](/cloud/plans-and-limits) per workspace.

The web app for signed-in users lives under `https://slugbase.app/app/…` (for example `/app/login`, `/app/bookmarks`). Marketing pages such as [Pricing](https://slugbase.app/pricing) and [Contact](https://slugbase.app/contact) are served at the site root.

## What is documented here vs in self-hosted guides
