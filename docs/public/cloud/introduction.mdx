## Overview

**SlugBase Cloud** is the hosted version of SlugBase — a bookmark manager with built-in URL shortening and keyboard-driven navigation. Save links in a **workspace**, assign short **slugs**, and jump to any destination from the address bar or command palette with `/go/<slug>`.

SlugBase Cloud runs on infrastructure operated by the SlugBase team. You sign up at [cloud.slugbase.app](https://cloud.slugbase.app), verify your email, and start working in a workspace without installing or maintaining servers.

## What you can do

- **Save and organize bookmarks** with folders, tags, and pinning
- **Assign slugs** and enable **forwarding** so signed-in members can open destinations quickly
- **Search and navigate** with the command palette (`⌘K` / `Ctrl+K`)
- **Import bookmarks** from browser exports (Chrome, Firefox, Safari)
- **Upgrade plans** when you need more bookmarks, AI suggestions, or team features

## SlugBase Cloud vs self-hosted

| Topic | SlugBase Cloud | Self-hosted |
|-------|----------------|-------------|
| Setup | Sign up and verify email | Install and run on your infrastructure |
| Billing | Free, Personal, and Team plans via **Settings → Billing** | No cloud billing — full features by default |
| Email | Operator-managed — you do not configure SMTP | Workspace admins can configure SMTP |
| Identity (SSO) | Available when enabled by the operator | Workspace admins configure OIDC providers |
| Bookmark cap | **50** bookmarks per workspace on Free | No cap by default |
| Workspaces | Free accounts include **one** workspace | Unrestricted workspace creation |

## Plans at a glance

SlugBase Cloud offers three plan tiers:

| Plan | Best for | Highlights |
|------|----------|------------|
| **Free** | Trying SlugBase | Up to **50** bookmarks per workspace, one workspace per account |
| **Personal** | Individual power users | Unlimited bookmarks, AI suggestions, additional workspaces |
| **Team** | Shared workspaces | Everything in Personal plus member management, teams, sharing, and audit log |

See [Plans and billing](/cloud/plans-and-billing) for upgrade paths and billing details.
