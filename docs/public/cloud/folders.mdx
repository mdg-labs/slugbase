## What you'll accomplish

After this guide, you can create folders, add bookmarks to them, and use folders to filter your bookmark list.

## Prerequisites

- Signed in to SlugBase Cloud
- Active workspace selected

<!-- screenshot:folders-list-overview -->

## Create a folder

<Steps>
  <Step title="Open Folders">
    From the sidebar, select **Folders**.
  </Step>
  <Step title="New folder">
    Click **New folder**, enter a name (for example, `Reading List`), and click **Create**.
  </Step>
  <Step title="Optional: icon and color">
    When editing a folder, you can set an optional icon and color to distinguish it in the list.
  </Step>
</Steps>

You can also create folders while editing a bookmark in the bookmark modal — type a new folder name in the folders field.

## Add bookmarks to folders

A bookmark can belong to **multiple folders**.

<Steps>
  <Step title="Edit the bookmark">
    Open a bookmark's **Edit** action from the bookmarks list.
  </Step>
  <Step title="Select folders">
    In the **Folders** field, search for existing folders or create a new one inline.
  </Step>
  <Step title="Save">
    Click **Save changes**. The bookmark appears when you filter by those folders.
  </Step>
</Steps>

Use **Move to folder** in bulk selection mode to move several bookmarks at once.

## Browse and filter by folder

On the **Folders** page:

- **Search** folder names
- **Sort** alphabetically, by bookmark count, or by recently created
- **Open in Bookmarks** from a folder's menu to see bookmarks in that folder

On the **Bookmarks** page, use the **Folder** filter to show bookmarks in a specific folder or **All folders**.

## Rename or delete a folder

<Steps>
  <Step title="Open folder actions">
    From the folders list, open the **More options** menu on a folder.
  </Step>
  <Step title="Rename">
    Choose **Rename**, enter a new name, and save.
  </Step>
  <Step title="Delete">
    Choose **Delete folder** and confirm. Bookmarks in the folder are **not** deleted — they move to your default folder.
  </Step>
</Steps>

## Sharing folders (Team plans)

On **Team** plans, workspace admins can share folders with teams or individual members. Sharing a folder grants read access to the bookmarks it contains. Folder sharing is not available on Free or Personal plans — see [Members and teams](/cloud/members-and-teams).

## Verify it worked

The new folder appears on the Folders page with an accurate bookmark count. Filtering bookmarks by that folder shows the bookmarks you assigned.

## Troubleshooting

### I do not see a folder I created

Confirm the correct workspace is active in the workspace switcher. Refresh the folders list.

### Bookmarks disappeared after deleting a folder

Bookmarks are not deleted with the folder. Check **All folders** on the bookmarks list — items moved to your default folder.
