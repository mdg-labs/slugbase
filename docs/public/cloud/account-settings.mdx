## What you'll accomplish

After this guide, you can update your profile, change your password, set personal preferences, and create API tokens for programmatic access.

## Account vs workspace settings

SlugBase separates settings by scope:

| Scope | Where to find it | What it controls |
|-------|------------------|------------------|
| **Account** | **Settings → Account** | Your profile, password, MFA, preferences, and API tokens — applies across all workspaces |
| **Workspace** | **Settings → Workspace** | Name, AI suggestions, and other workspace-wide options (admins and owners) |
| **Billing** | **Settings → Billing** | Plan, subscription, and seats (workspace owner) |

This page covers **account** settings only.

## Open account settings

<!-- screenshot:cloud-account-settings -->

From the sidebar, open **Settings**, then choose **Account**. Sections appear in the settings navigation: **Profile**, **Password**, **Two-factor auth**, **Preferences**, and **API tokens**.

## Profile

Update your display name and email address.

<Steps>
  <Step title="Edit your name">
    Change **Display name** and save. This name is visible to other members in shared workspaces.
  </Step>
  <Step title="Change your email">
    Enter a new email address and save. SlugBase sends a verification link to the new address. Your email does not change until you confirm the link.
  </Step>
</Steps>

You can cancel a pending email change or resend the verification message from the same screen.

## Password

If you signed up with email and password, update your password here. You must enter your current password first.

If you sign in only through a federated provider (for example, Google or an OIDC identity provider), you can **add** a password for direct sign-in without losing federated access.

## Preferences

Personal preferences apply only to your account, not the whole workspace:

| Setting | Options |
|---------|---------|
| **Language** | English or Deutsch (German) |
| **Theme** | Light, dark, or auto |
| **Accent color** | Periwinkle, indigo, teal, and others |
| **Default bookmark view** | Card grid or table |
| **AI suggestions opt-out** | Disable AI features for your content when the workspace has AI enabled |

## API tokens

Personal API tokens let scripts and tools authenticate as you. Tokens are **not plan-gated** on any tier.

<Steps>
  <Step title="Create a token">
    Open **API tokens**, click **New token**, and give it a descriptive name (for example, "CI import script").
  </Step>
  <Step title="Copy the token">
    SlugBase shows the token **once**. Copy it immediately and store it securely.
  </Step>
  <Step title="Use the token">
    Send the token as a Bearer token in API requests. See the API reference for endpoint details.
  </Step>
</Steps>

<Callout kind="danger">
API tokens bypass the interactive MFA step during sign-in. Treat them like passwords — revoke any token you no longer need.
</Callout>

You can revoke tokens individually from the same list. Each account has a maximum number of active tokens.

## Verify it worked

- Profile changes appear after save (email changes after verification)
- Preferences apply on your next page load
- New API tokens appear in the list with creation date and last-used metadata
