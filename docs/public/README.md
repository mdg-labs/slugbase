# SlugBase public documentation (source)

Customer and operator documentation for [Documentation.AI](https://documentation.ai). Content here is authored as MDX and synced to [`mdg-labs/slugbase-docs`](https://github.com/mdg-labs/slugbase-docs) on push to `main` (see [#396](https://github.com/mdg-labs/slugbase/issues/396)).

**Layout:** This directory mirrors the `slugbase-docs` repository root exactly. Paths under `docs/public/` become the same paths at the publish repo root after sync.

**Navigation:** `documentation.json` controls site branding, navbar links, and sidebar structure.

**Not here:** Engineering specs, design prototypes, and agent tooling live under [`docs/internal/`](../internal/) and are never synced.
